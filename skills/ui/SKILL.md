# UI implementation

Use semantic elements and native controls first. Preserve keyboard operation, visible focus,
labels, error association, and meaningful status announcements. Check responsive behavior at the
smallest and largest supported layouts.

Model loading, empty, error, disabled, and success states explicitly. Test user-visible behavior
at the lowest reliable layer; use end-to-end tests for critical cross-component journeys.
